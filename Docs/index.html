Ver el código y el estado del proyecto

Explora y organiza

Busca por etiquetas, categoría, color, resolución y proporción. Guarda favoritos, descarga los originales y organízalos en carpetas. La categoría Anime contiene imágenes.

Adáptalo a tus pantallas

Elige una imagen por pantalla o un fondo común. Ajusta el recorte, el zoom y la relación de aspecto, o utiliza el relleno desenfocado para imágenes verticales. Programa la rotación por carpetas en orden aleatorio o secuencial.

Conserva tu biblioteca

El traslado de carpetas y la sincronización local o WebDAV se limitan a imágenes registradas de Wallhaven. Los archivos antiguos de otras funciones se conservan.

Estado de distribución

No hay una versión estable publicada de este fork. Los paquetes locales Debug requieren macOS 14.4 o posterior; la firma Developer ID y la notarización deben completarse antes de distribuirlos públicamente.
